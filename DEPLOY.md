# Deploy to Vercel - Get Live URL

## Quick Deploy (Recommended)

### Method 1: Deploy via Vercel CLI

1. Install Vercel CLI:
```bash
npm i -g vercel
```

2. Deploy (from project directory):
```bash
vercel
```

3. Follow prompts:
- "Set up and deploy?" → Yes
- "Which scope?" → Your account
- "Link to existing project?" → No
- "What's your project's name?" → frame-fables
- "In which directory is your code located?" → ./

4. Get your live URL (e.g., https://frame-fables.vercel.app)

### Method 2: Deploy via GitHub (No CLI needed)

1. Go to https://vercel.com/new
2. Import your GitHub repository
3. Click "Deploy"
4. Get your live URL in ~2 minutes

## Alternative: Run Locally on Your Machine

1. Clone the repo to your local machine:
```bash
git clone <your-repo-url>
cd FPS-
git checkout claude/frame-fables-marketing-app-011CUKa8pfz5g5CnZR9kQzsa
```

2. Install and run:
```bash
npm install
npm run dev
```

3. Open http://localhost:3000 in your browser
