## 🎯 7-SECOND HOOK TEMPLATES

**Formula**: "[Specific $ amount] + [timeframe] + [method preview]"

**Examples**:
1. "I made $12,453 last month using these 3 AI tools" *(show earnings screenshot)*

**Formula**: "[Controversial statement] + [dramatic pause/reaction]"

### Script Direction Notes for AI Voice

**Add these tags in your script for better AI delivery**:

**Emphasis**:
- Use CAPS for words to emphasize: "This is INSANE"
- Or use asterisks: "This is *actually* crazy"

**Pauses**:
- Use ellipsis for dramatic pause: "And the result was..."
- Use [pause] for longer breaks: "Wait for it [pause] amazing!"

**Emotion**:
- Add emotion tags: "[excited] This is incredible!"
- Add tone tags: "[whisper] Here's the secret"

**Pacing**:
- Speed up: "[fast] Number 5, 4, 3, 2, 1"
- Slow down: "[slow] Listen carefully to this part"

## 🎨 VISUAL DIRECTION NOTES

### Screen Recording Best Practices

**Before Recording**:
- [ ] Close unnecessary tabs/apps
- [ ] Clear desktop clutter
- [ ] Set browser to incognito (clean UI)
- [ ] Zoom to 150% for mobile viewers
- [ ] Hide personal info/emails

**During Recording**:
- [ ] Slow, deliberate cursor movements
- [ ] Click and hold briefly (easier to see)
- [ ] Zoom in on important text
- [ ] Use smooth scrolling
- [ ] Keep actions under 3 seconds each

**After Recording**:
- [ ] Speed up boring parts (2-3x)
- [ ] Add cursor highlight/circle
- [ ] Zoom/crop to focus area
- [ ] Add arrows/highlights in post

---

### Text Overlay Guidelines

**Readability**:
- Font: Bold sans-serif (Montserrat, Poppins)
- Size: Fill 60-80% of screen width
- Color: White with black stroke, or vice versa
- Position: Top third or bottom third
- Duration: 1-2 seconds per short phrase

**Timing**:
- Sync text to voice narration
- One phrase at a time
- Fade in/out (0.2 seconds)
- Never obscure important visuals

**Hierarchy**:
- Main point: Largest, centered
- Supporting: Medium, underneath
- Numbers/data: Bold, contrasting color
- CTAs: Different color + animation

---

### Caption/Subtitle Best Practices

**Auto-Captions (CapCut, Descript)**:
- Style: Modern, animated
- Position: Center or lower third
- Color: Yellow or white
- Effect: Word-by-word highlight
- Background: Semi-transparent box

**Manual Captions**:
- Keep to 5-7 words per line
- Sync precisely with audio
- Use emoji for emphasis 💰
- Change color for important words
- Add sound effect text [BOOM!]

## 📊 SCRIPT PERFORMANCE OPTIMIZATION

### A/B Test These Elements:

**Hooks**:
- Question vs. Statement
- Money number vs. Time savings
- Personal vs. General

**Video Length**:
- 15 seconds vs. 30 seconds
- Quick cut vs. Detailed explanation

**CTA Placement**:
- Mid-video vs. End-video
- Verbal vs. Text overlay

**Visual Style**:
- Screen recording vs. Stock footage
- Face vs. Faceless
- Text-heavy vs. Visual-heavy

### Track Metrics:
- Average watch time (aim for 70%+)
- Click-through rate on bio link (aim for 5%+)
- Comments/engagement (aim for 2%+)
- Shares (viral indicator)
